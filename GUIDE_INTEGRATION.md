# «Лето в удмуртской деревне» v0.41 на портале

Основной вход сохранён: `apps/guide/index.html`, ID модуля `guide`.
На главной карточка обновлена до 20 глав. Сборка содержит 68 сцен, 95 заданий, 145 исходных аудиофайлов (134 активных) и все готовые иллюстрации v0.41. Незавершённые 24 рисунка не выдаются за готовые: используются имеющиеся задания и текстовые карточки.

## Редактирование

- `content/guide-course.json` — действующие реплики, переходы, ввод слов и задания. В Pages CMS добавлен раздел «Лето в деревне · сцены и реплики» для текстов. Остальные поля полного курса редактируются в JSON; стабильные ID нельзя менять.
- `content/guide-vocabulary.json` — явный словарный каталог и соответствия форм исходным словам; суффиксы автоматически не угадываются. При добавлении нового слова в курс добавьте его сюда, а при переименовании измените обе записи с сохранением ID.
- `apps/guide/audio-manifest.json` и `.js` — соответствия аудиофайлов словам. Для изменения звука обновляются оба представления; отдельные файлы хранятся в `media/audio`.
- `python3 tools/build_content.py --publish` проверяет материалы, собирает `course.js`, общий словарный каталог и `_site` для GitHub Pages. Папка `_site` не хранится в Git.

## Словарь

Каталог регистрируется без открытия всего списка. Слова открываются при фактическом показе в игре, в том числе озвученное слово внутри реплики. Игровой словарь и общий словарь получают одинаковые встречи. Ошибки по размеченным словам передаются общему тренажёру. Одинаковые единицы других игр используют общие canonicalId. Например, нянь в самоучителе и магазине остаётся одной записью, а дэремъёс связано с дэрем. Переходы в общий словарь не меняют игровые баллы.

## Сохранения

Ключ нового курса — `uston_game_v036`, заметок — `uston_notes_v036`. Оба входят в общий экспорт/импорт портала. Сохраняются рисунки, работы, текст рассказа, ответы и навигация. Прежние ключи `udmurt_story_progress_v031` и `udmurt_v026_dictionary` не удаляются; прежние слова переносятся по явным ID. Старые пройденные упражнения v0.34 не объявляются автоматически пройденными в новом, отличающемся курсе.

Родительский портал и игра обмениваются только с доверенным same-origin окном и правильным протоколом. Возврат «На портал» работает внутри iframe и при прямом открытии игры. Сохранение передаётся при возврате; данные хранятся в этом браузере и на этом origin. Ранее скачанный локальный файл v0.41 можно восстановить в настройках самой игры.

# Словарь и короткие повторения: версия для просмотра

19 ноября 2026. Основа — shidaria98-code/uston1, main, 9169305a795b5ade51c573fa5080ad0358975a42. Сборка проверена локально перед переносом в GitHub.

## Что можно попробовать

В полном портале: «Моё пространство» → «Мой словарь» → «Повторим слова». Если словарь пуст, сначала открыть слова в играх/самоучителе. Тренажёр использует личный накопленный словарь.

Для быстрого знакомства открыть `training-demo.html`: восемь настоящих слов из портала, временные данные в памяти страницы, без записи в профиль. После перезагрузки демонстрация начинается заново. Демонстрация не включается в публикацию `_site`.

## Правила первой версии

- Оставлены перевод в двух направлениях и ввод по иллюстрации без русского перевода. Иллюстрации повторно используются из «Мы сеем» и обновляются вместе с ними через CMS. Для слов без картинки выбирается текстовый формат.  Чередование сохраняется между сессиями, даже если открыто только одно слово.
- Одна словарная форма — одна карточка с накоплением утверждённых переводов через запятую. Совпадения регистра, Unicode NFC и случайных пробелов объединяются. Значения одинакового написания намеренно объединены согласно уточнению заказчика.
- Ввод принимает словарную форму и явно объявленные допустимые формы. Суффиксы автоматически не удаляются. Для удмуртских букв есть экранные кнопки.
- Обычная сессия: до десяти ответов, ориентир три минуты. После трёх минут завершается при переходе к следующему вопросу; через пять минут заканчивается автоматически. Можно закончить раньше. Неотвеченный вопрос не считается ошибкой.
- Приоритетные трудные слова чередуются со словами, которые давно не повторяли. Это обеспечивает охват остального словаря. При равной срочности и сложности порядок перемешивается алгоритмом Фишера — Йетса; варианты ответа тоже перемешиваются. Берутся слова, срок повторения которых наступил; если таких нет, доступно добровольное повторение.
- После ошибки слово можно ещё один раз встретить в конце текущей сессии, в пределах общего лимита. Следующее плановое повторение — через десять минут.
- После последовательных верных ответов интервалы: 1, 3, 7, 14, 30 дней; далее 30 дней. Ошибка сбрасывает последовательность. Пропуск дня не отнимает баллы.
- История ошибок в играх повышает приоритет слова, но сама по себе не продвигает интервальное расписание успешных тренировок. Нет штрафов XP и дополнительных игровых баллов за тренажёр.

Это прозрачный настраиваемый алгоритм для апробации, не результат педагогической валидации. Учёным можно показать поведение, интервалы и правила проверки ответа; затем скорректировать параметры. Автоматических уведомлений при закрытом браузере нет: срок определяется при возвращении на портал.

## Какие ошибки игр учитываются

1. «Мы сеем»: завершённый раунд со словом, в котором были неверные буквы. Раунд считается одним наблюдением; подсказка сама по себе не объявляется ошибкой.
2. «Кытын — Кытчы — Кытысь»: неверные попытки собрать форму связаны со словарной основой.
3. Самоучитель: выбор неверного соответствия в словарных парах и неверный порядок частей при сборке слова. Верные результаты тоже передаются, но не заменяют расписание повторения тренажёра.

У Memory несовпавшая пара проверяет расположение картинок, у «Кин та?» неверный выбор имени не указывает однозначно на незнание отдельного слова. Эти результаты не объявляются лексическими ошибками. Историческую частоту ошибок, которую старые игры не записывали, задним числом не выдумываем. Новые наблюдения учитываются после установки обновления.

## Что изменилось в хранении

Общий модуль `assets/dictionary-core.js` собирает словарные единицы, переводы, источники и ответы. Постоянные ID текущих единиц хранятся в `content/vocabulary-identities.json`; они отделены от отображаемого написания и игровых индексов.

Накопление записано журналом отдельных событий в localStorage, а не перезаписью одного общего массива. Независимые записи двух вкладок не перекрывают друг друга. Повторная доставка события с тем же ID безопасна. Это уточнение первоначального предложения: для данной версии применён журнал событий вместо перехода всего портала на IndexedDB. При заполнении/блокировке хранилища остаётся временный буфер и показывается предупреждение; требуется скачать сохранение до закрытия страницы.

Старые ключи игр и словаря сохранены. Старые открытия переносятся, неизвестные ID остаются видимыми как прежние записи и исключаются из вопросов, пока неизвестен перевод. Источники восстанавливаются из доступных доказательств; неподтверждённый источник обозначается «Ранее открыто». Падежная игра не приписывает открытию ложное посещение самоучителя. Сброс её результата не стирает сохранённый источник знакомства.

Экспорт обновлён до версии 2 и включает историю повторений. Импорт версий 1 и 2 поддерживается; словарь накапливается объединением. Игровая часть сохраняет прежнюю проверку и откат при ошибке записи. Исправлена ошибка старого валидатора, который принимал дополнительные словарные ключи за сохранение пятнашек. Старый опубликованный портал не поддерживает новый экспорт v2 — для обратного переноса используйте прежнюю резервную копию.

## CMS и будущие игры

В CMS добавлены «Повторение слов — настройки» и «Слова новых игр». Заголовок, описание, интервалы и длительность вынесены в `content/training.json`; сборка проверяет диапазоны.

Предварительно вручную наполнять глобальный словарь не требуется. Сборщик автоматически читает JSON новых игр в `content/`, если в них объявлены `gameId` и `vocabulary` либо `questions[].vocabulary`. Данные слов остаются рядом с заданиями игры. Пример структуры (технический пример, не готовый вопрос):

```json
{
  "gameId": "history-quiz",
  "questions": [
    {
      "id": "q01",
      "vocabulary": [
        {"u": "кион", "ru": "Волк"}
      ]
    }
  ]
}
```

На вопрос разрешено до двух единиц. Идентификаторы новых связей создаются автоматически из игры, элемента и словарной формы; порядок двух слов не определяет их идентичность. Повторение слова в других вопросах сохраняет одно понятие. Сборка дополняет постоянный реестр. Не удалять реестр из обновлений.

Игра подключает `assets/dictionary-game.js`. После показа слов вызывает `UstonWords.encounter(gameId, wordIds)`, а для лексического ответа — `UstonWords.result(gameId, wordId, correct)`. ID доступны в скомпилированном `assets/vocabulary-extra.js`. Для встраивания нового модуля по-прежнему нужна его регистрация в каталоге портала; ядро словаря переписывать не требуется. Разметка CMS самой будущей викторины добавляется вместе с её готовой структурой.

Если исправляется написание существующей словарной единицы со стабильным исходным ID, её постоянный ID сохраняется. При замене понятия другим нужно новое исходное ID слова; не переиспользовать старое для другого понятия. Редакторские неоднозначности прошлых замен по индексу нельзя надёжно восстановить без исходных данных.

Новая сборка самоучителя ещё не получена. Его сюжет, реплики и дополнительные слова не выдумывались. Текущий самоучитель отдаёт открытия и словарные ошибки тренажёру; перенос обновлённого текста самоучителя в CMS выполняется после получения сборки.

Существующие правила открытия слов по посещениям/прогрессу, в частности списки «Семьи», чисел и «Кин та?», сохранены в этом этапе. Их перевод на точные события показа каждой подписи — отдельная доработка адаптеров. Эта версия не заявляет, что весь первоначальный аудит всех 13 источников реализован полностью.

## Правки после просмотра

Кнопка «Проверить» получила общий стиль всех кнопок тренажёра: шрифт, скругления и размер области нажатия. Добавлен ввод по картинке; иллюстрации взяты из существующей игры, подписи и переводы до ответа не показываются. Из задания с картинкой можно перейти к текстовому без регистрации ошибки.

Картинки людей и абстрактных понятий по умолчанию исключены из ввода без перевода: например, одиночный женский портрет не позволяет надёжно различить «женщина», «мама», «сестра». В CMS у слов «Мы сеем» добавлен переключатель пригодности картинки для этого задания. Это не меняет содержание самой игры.

По итогам согласования задания с пропущенными буквами удалены. Если изображение отсутствует, не подходит или не загрузилось, ученику показывается русский перевод и предлагается ввести полное удмуртское слово.

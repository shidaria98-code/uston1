# Кытын? Кытчы? Кытысь? · MVP для «Усьтона»

Браузерная игра: 10 групп, 30 русско-удмуртских предложений, 3 последовательных уровня. Запускается без сборки и библиотек. Откройте index.html или разместите папку на статическом сервере. Для общего словаря игра и портал должны работать на одном адресе HTTP(S); поведение localStorage для отдельных file:// зависит от браузера.

## Правила
Русское предложение и удмуртский текст видны сразу; только целевая форма заменена пропуском. Выбранные элементы заполняют его. Для сюрес/пужым собирается сочетание с отдельным послелогом выл. Справка объясняет, что выл обозначает верх, поверхность и не соответствует любому русскому «на».

Две попытки: 10/5/0 баллов. После двух ошибок показывается правильный ответ. Любое ошибочное задание возвращается один раз в конце уровня без дополнительных баллов. После двух ошибок в повторе показывается объяснение и разрешается двигаться дальше. Максимум 300 баллов.

Все авторские переводы сохранены, включая «Песятае» и «Песятай куалаын» без добавленного глагола или точки. Русская пара «Мальчик выходит из дома.» восстановлена из согласованного контекста; удмуртская строка не менялась.

## Иллюстрации
Подключены реальные исходники из папки «Грамматический тренажер - изображения» на рабочем столе. 30 заданий используют 29 отдельных исходных сцен. Сцена дедушки у порога куалы повторяется для «где» и «откуда»: отдельного изображения выхода нет. Остальные предоставленные дубли не использованы.

images-manifest.json содержит соответствие каждой сцены заданию, исходное имя, SHA-256 и замечания о содержании. images-map.js задаёт реальные пути. WebP сохранены без изменения; PNG экспортированы в JPEG для уменьшения размера без обрезки и перерисовки. На карточке каталога используется приложенная заставка «Кытын? Кытчы? Кытысь? — Удмуртская деревня». Исходники пользователя не менялись.

Некоторые сцены не полностью совпадают с текстом: молодой путешественник вместо папы у города, мальчик вместо папы у лавки, девушка с яблоком у прилавка вместо мамы с хлебом. Они подключены по пространственному отношению; авторские предложения не подгонялись под картинки. Все такие соответствия отмечены в реестре.

## Автоматический словарь
После выполненного задания (правильного ответа или показа ответа после двух ошибок) dictionary.js добавляет начальную форму в `uston-hub-dictionary-v1`. Первая ошибка ещё не открывает слово. Существующие ID общего лексикона используются для корка/гурт/шур/сюрес/пужым; для кар/лавка/инты/куала/гур добавлены записи. Проверяются все ID того же слова: ранее открытые записи не дублируются. Сохраняется словарная форма из утверждённой группы, а не результат автоматического отсечения окончания.

Три падежа, повторы и повторное прохождение не создают дополнительные записи. Сброс игры сохраняет словарь. При загрузке автоматически учитываются ранее пройденные задания. Слова доступны в «Моё пространство → Мой словарь» и входят в стандартное резервное сохранение словаря портала. Ошибка записи показывается пользователю; при следующем ходе выполняется повторная попытка.

## Интеграция
Обновлены public-release и work/uston-current. Архив обновления портала содержит index.html, три модуля словаря в assets/ и games/case-lock/. Применяется поверх актуальной сборки портала; это не полный самостоятельный сайт.

Технический ID `case-lock` и ключ `uston.case-lock.v1` сохранены: переименование не сбрасывает прогресс. Сохраняются очередь, текущие элементы, попытки, повторы, баллы и завершённые замки. `window.UstonCaseLock.getProgress()` возвращает копию сводки; `storageKey` содержит ключ сохранения.

Событие `uston:case-lock` содержит данные в detail. В iframe того же origin отправляется `postMessage({type:'uston:game-progress',payload},location.origin)`. Родитель проверяет origin, source, gameId и schemaVersion. Поля payload: schemaVersion, gameId, runId, eventId, type, score, maxScore, completedLevels, words [{udm,ru}], finished. Баллы передаются как текущая сумма, не как приращение. Общий счёт и серверная проверка результатов пока не подключены. Другие игры и их баллы не менялись.

## Возврат к пройденным заданиям
«← Назад» открывает историю выполненных шагов, включая повторы ошибок и предыдущие замки. В просмотре показаны картинка, русский и удмуртский текст, правильная форма, объяснение и сохранённый ответ игрока. Изменять пройденный ответ нельзя. «Вперёд →» доступно только внутри истории и до текущего шага; перейти к непройденному заданию нельзя. «К текущему шагу» возвращает к месту прохождения. Баллы, попытки, очередь повторов и выбранные элементы текущего задания не меняются. История и место просмотра сохраняются после перезагрузки. На первом шаге кнопка «Назад» отключена. История доступна и с экранов завершения замка/игры.

Старые сохранения без истории не сбрасываются: пройденные задания текущего замка восстанавливаются в сохранённом порядке очереди. Для ранее законченных замков восстанавливаются слова, но их первоначальный случайный порядок и ответы не были сохранены — эти записи помечены как ранее выполненные. Новые прохождения сохраняют точный порядок и ответы.

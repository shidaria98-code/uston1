# Замок спряжения

Локальная интеграция в портал «Усьтон» на базе `main` `c0568917b41bae9dd79f4f7034c99da7caf9b379`. Публикация не выполнялась.

`index.html` — самостоятельная игра с встроенными данными, кодом и шестью PNG. Её можно открыть без сервера. Для общего словаря и профиля запускайте игру из каталога локального портала.

Игра содержит 20 глаголов, изучение и тренировку двух пропущенных форм каждого, а также 20 утверждённых предложений. «Последний ключ» случайно выбирает до десяти разных вопросов. Слова открываются по мере показа; глаголы поступают в словарь в инфинитиве.

## Редактирование

Единственный редактируемый источник материалов — `content/conjugation-lock.json` в корне портала. В Pages CMS добавлен раздел «Замок спряжения». `games/conjugation-lock/data.json`, `index.html` и `assets/conjugation-data.js` создаются сборкой; их не редактируют независимо.

Команда из корня портала:

```sh
python3 tools/build_content.py --publish
```

Она создаёт локальную папку `_site`, но ничего не отправляет в GitHub. Для проверки:

```sh
python3 -m http.server 8785
```

Откройте `http://127.0.0.1:8785/#conjugation-lock`. Чтобы пересобрать только отдельный HTML из уже сгенерированных данных, используйте `python3 build.py` из папки игры.

## Сохранения

Ключ и формат исходной игры сохранены: `uston.conjugation-lock.save.v1`, версия 1. Игра входит в общий экспорт/импорт портала; собственные кнопки переноса тоже работают. Неподтверждённые события хранятся до сохранения общего словаря. Перенос отдельного игрового файла восстанавливает слова и тогда, когда на исходном устройстве события уже были подтверждены.

Словарные карточки и ранее открытые слова не сбрасываются при импорте более раннего игрового снимка. Состояние самой игры восстанавливается из выбранного файла. Неизвестные задания сохраняются в архивных полях, конфликтующий локальный снимок — в `recoveredStandalone`; нечитаемое исходное сохранение — в `recovery`. При запрете хранения доступен экспорт, но закрытие страницы без скачивания файла может потерять временные изменения.

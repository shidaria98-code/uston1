Архив UPDATE требует существующие файлы версии 0.16 или 0.16.1.

ОБНОВЛЕНИЕ GITHUB ЧЕРЕЗ САЙТ
1. Распакуйте uston_v17_update.zip. ZIP целиком загружать не нужно.
2. В корне своего репозитория: Add file → Upload files.
3. Перетащите index.html, README.txt, README_UPDATE.txt и папки assets и games ИЗ АРХИВА UPDATE.
4. Commit changes. Существующие файлы с совпадающими путями будут обновлены; остальные останутся.
5. Не удаляйте прежние папки assets, games и apps. В games должны появиться три новые папки рядом с udmurtia.
6. Дождитесь публикации GitHub Pages и обновите страницу. При старом каталоге выполните жёсткое обновление.

Новое обновление меньше 100 файлов; самый большой новый файл — около 2 МБ.
Оно содержит весь новый index.html, включая исправленную заставку. Отдельно применять 0.16.1 не нужно.

УСТАНОВКА В СУЩЕСТВУЮЩИЙ РЕПОЗИТОРИЙ shidaria98-code/uston1
1. Распакуйте архив на компьютере. ZIP-файл загружать как файл сайта не нужно.
2. На GitHub откройте корень репозитория → Add file → Upload files. Перетащите index.html и папки assets и games из распакованного архива. Сохраните замену файлов. Папки apps и остальные игры в репозитории оставьте на месте: архив дополняет существующий сайт.
3. Дождитесь успешного завершения GitHub Actions / Pages. Обновите сайт Cmd+Shift+R (Mac) или Ctrl+Shift+R (Windows). Сохранения браузера не очищайте.

В assets включены все 41 файла программ старых игр, чтобы при загрузке не потерять необходимые зависимости. Новая игра находится в games/culture-memory/index.html. Перед обновлением можно скачать сохранение в пространстве игрока.

Шудон: 5/10/20 пар, справки о 20 предметах, перемешивание при новой партии, пауза, продолжение и рекорды; подписи «Сюй мунё» и «Россиен валче».
